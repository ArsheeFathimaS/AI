# MyZayna – Real‑Time AI Voice Mentor with Lip‑Sync Avatar

**Frontend (live):** https://myzaynafrontend.vercel.app/  
**Backend (live):** https://myzayna-backend.onrender.com

MyZayna is a web app that enables near‑real‑time **voice↔voice** conversations with an AI mentor. 
It renders a **3D avatar** (React Three Fiber) and synchronizes mouth shapes using **Rhubarb Lip Sync** from the audio generated by TTS.

## ✨ Key Features

- **Voice & Text Chat** with an AI model (OpenAI SDK).
- **3D Avatar** driven by blendshapes/visemes (`/public/models/*.glb`).
- **Lip‑Sync** via **Rhubarb** JSON transcript + audio timestamps.
- **Low‑friction Frontend** using Vite; **CORS‑enabled Backend** for cross‑origin calls.
- **Configurable API URL** via `VITE_API_URL` (already set in `myzayna_frontend/.env`).

## 🚀 Getting Started

### 1) Backend (Node/Express)

```bash
cd myzayna_backend/myzayna_backend_main

# install deps
npm install

# copy env and set your key
cp .env.example .env
# Edit .env -> set OPENAI_API_KEY=sk-... and optional PORT

# make rhubarb executable (Linux/Mac)
npm run start   # starts server (also runs: chmod +x tools/rhubarb/rhubarb && node index.js)
# or live reload for dev:
npm run dev
```

**Endpoints**
- `POST /chat` — expects JSON body `{"message":"Hello"}`.  
  Returns `{"messages": [...]}` and writes audio + lipsync JSON into `audios/message_*.{mp3,wav,json}` (see `index.js`).  
  The server uses **ffmpeg** to convert MP3 → WAV and **Rhubarb** to produce visemes.

> Ensure **ffmpeg** is installed and available in `PATH`.  
> Rhubarb binary is expected at `tools/rhubarb/rhubarb` (Linux/Mac) or `tools/rhubarb/rhubarb.exe` (Windows).

### 2) Frontend (React + Vite)

```bash
cd myzayna_frontend
npm install

# .env already exists with backend URL:
# VITE_API_URL=https://myzayna-backend.onrender.com
# change it to your local server when developing:
# VITE_API_URL=http://localhost:3001

# run locally
npm run dev

# build for production (used by Vercel)
npm run build
```

Open `http://localhost:5173` in your browser.

## 🎮 Frontend Components (selected)

- `src/components/Avatar.jsx` – loads GLB models and drives blendshapes; consumes visemes via `useChat` state.
- `src/components/Experience.jsx` – scene setup (lights/camera).
- `src/components/UI.jsx` – chat UI / controls.
- `src/components/VoiceStreamer.jsx` – handles mic capture & playback.
- `src/hooks/useChat.jsx` – central state; posts to `{VITE_API_URL}/chat` and manages `messages`.

## 🧪 Quick Smoke Test

1. **Backend** running → `curl -X POST http://localhost:3001/chat -H "Content-Type: application/json" -d "{"message":"hello"}"`  
2. **Frontend** set `VITE_API_URL=http://localhost:3001` → start `npm run dev`, send a text message in the UI.  
3. Confirm: you see a reply, audio plays, and the avatar mouths the words.

## 📦 Deployment Notes

- **Vercel (Frontend):** just `npm run build`. Ensure `VITE_API_URL` is set to your live backend URL.
- **Render (Backend):** set env `OPENAI_API_KEY`; build command `npm install`, start command `npm start`.  
  Bundle the Rhubarb binary for your Render environment, or disable lipsync if not available.
